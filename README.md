# NishantX Portfolio

Premium digital portfolio experience.

## Stack

Next.js · TypeScript · Tailwind CSS · GSAP · Lenis · Framer Motion · Three.js · R3F · Drei · Shadcn UI

## Develop

```bash
npm install
npm run dev
```

## Architecture

- `src/providers` — Theme, Lenis, Cursor, Animation, Three
- `src/animations` — GSAP utilities, motion variants, text splitting
- `src/components` — UI, sections, background, cursor systems
- `src/three` — Lightweight WebGL scene
- `src/config` — Site, SEO, fonts, theme tokens
- `public/fonts` — Clash Display, Satoshi (local)

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint
